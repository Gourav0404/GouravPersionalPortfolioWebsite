# Assets to add

This folder is empty on purpose — drop your real image files in here using
these exact names, and every page will pick them up automatically (no code
changes needed):

- `profile.jpg` — your photo, used in the Home hero section
- `project-1.jpg`, `project-2.jpg`, `project-3.jpg` — project previews
- `certificate-1.jpg`, `certificate-2.jpg`, `certificate-3.jpg` — certificate scans

Until you add them, each card shows a clean placeholder instead of a broken
image icon, so the site still looks intentional.

To change file names or add more projects/certificates, edit:
`src/data/projects.js` and `src/data/certificates.js`.
